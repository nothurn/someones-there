## ★ Two real compile errors beyond the Forge→NeoForge port — genuine 1.20.1-only vanilla API differences

These are **not** Forge/NeoForge API differences at all — they're vanilla
Minecraft API changes between 1.20.1 and 1.21.1, exactly the kind RECOVERY.md
section 8 warns about, and the only two places in this whole session where
the initial build actually failed to compile after the "obvious" port:

1. **`entity/PeripheralFigureEntity.java`**: `defineSynchedData()` took zero
   arguments at 1.20.1 (RECOVERY.md: *"die Builder-Signatur ist erst
   1.20.5+"*) — at 1.21.1 the override must accept a
   `SynchedEntityData.Builder` and pass it to `super.defineSynchedData(builder)`.
   Fixed by matching the real 1.21.1 sibling's signature exactly.
2. **`client/renderer/PeripheralFigureRenderer.java`**: `new ResourceLocation(String, String)` — a public constructor at 1.20.1, but RECOVERY.md
   section 8 explicitly flags this can't be trusted from jar inspection alone
   ("`fromNamespaceAndPath` lässt sich oft nicht auflösen, obwohl es im
   dekompilierten Jar vorhanden aussieht — über einen echten Build
   verifizieren"). **This is exactly what happened**: the real compiler
   confirmed the constructor is private at 1.21.1 and
   `ResourceLocation.fromNamespaceAndPath(namespace, path)` is required
   instead — verified via an actual failing build, then confirmed against
   the real 1.21.1 sibling file, not guessed from the jar.

## Judgment call: `bus = Bus.MOD` kept, not dropped

Unlike the FORGE-bus event handlers across every mod ported so far (which
lose their `bus=` parameter entirely in modern NeoForge's `@EventBusSubscriber`),
`registry/PeripheralFigureAttributes.java` and
`client/PeripheralFigureClientEvents.java` both declare `bus = Bus.MOD`
(registry/mod-lifecycle events, not game events) — and this **is** still
required in 1.21.1/moddev 2.0.141, confirmed by reading it directly in the
real, already-published `peripheralfigure-neoforge-1.21.1` decompile. The
compiler flags it as `@Deprecated(forRemoval=true)` (a future-removal
warning, not an error) — left as-is since it matches real shipped code for
this exact NeoForge version, not modernized further, since a replacement
mechanism isn't yet confirmed to exist and isn't required.
